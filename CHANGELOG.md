## [1.1.0] - 2026-01-08

### Added

- Ability to encrypt the contents of a file to a string
- Option to output encrypted string in a Spring Boot compatible wrapper
- String decryption accepts Spring Boot wrapper
- Multiple ways to specify the encryption/decryption password
- Example project
